# Browser Tag Capture Mode - Feature Summary

## Overview

The browser tag now supports **capture mode**, enabling dynamic HTML generation inspired by the original MASK design philosophy. This allows subroutines to generate HTML fragments that compose into complete web pages.

## Two Rendering Modes

### 1. Literal Mode (Default)
```xml
<browser>
  <html>
    <body><h1>Static HTML</h1></body>
  </html>
</browser>
```
- HTML content is treated as literal text
- No DIRAC processing of children
- Fast, simple, direct rendering

### 2. Capture Mode
```xml
<defvar name="userName" value="Alice" />

<subroutine name="greeting">
  <h2>Welcome, <variable name="userName" />!</h2>
</subroutine>

<browser mode="capture">
  <html>
    <body>
      <call name="greeting" />
    </body>
  </html>
</browser>
```
- DIRAC executes all children
- Variables are expanded inline
- Subroutines generate HTML fragments
- Unknown tags output as literal HTML
- Perfect for dynamic dashboards

## Technical Implementation

### 1. DiracSession Extension
**File**: `src/types/index.ts`
```typescript
export interface DiracSession {
  // ... existing fields
  literalHTML?: boolean;  // NEW: Flag for HTML generation mode
}
```

### 2. Interpreter Enhancement
**File**: `src/runtime/interpreter.ts`

Added `renderAsHTML()` function:
```typescript
async function renderAsHTML(session: DiracSession, element: DiracElement): Promise<void> {
  // Converts DIRAC elements to HTML strings
  // Handles attributes, text content, children
  // Supports self-closing tags
}
```

Modified default case in `integrate()`:
```typescript
default:
  const subroutine = getSubroutine(session, element.tag);
  if (subroutine) {
    await executeCall(session, element);
  } else if (session.literalHTML) {
    await renderAsHTML(session, element);  // NEW
  } else {
    // Just process children
  }
```

### 3. Browser Tag Update
**File**: `src/tags/browser.ts`

Added capture mode support:
```typescript
if (modeAttr === 'capture') {
  // Enable HTML generation mode
  const prevLiteralHTML = session.literalHTML;
  session.literalHTML = true;
  
  // Capture output
  const oldBoundary = setOutputBoundary(session);
  
  for (const child of element.children) {
    await integrate(session, child);
  }
  
  htmlContent = popAndCaptureOutput(session);
  session.outputBoundary = oldBoundary;
  session.literalHTML = prevLiteralHTML;
}
```

## Use Cases

### 1. Dynamic Dashboards
```xml
<subroutine name="metric-card">
  <div class="card">
    <h3><variable name="title" /></h3>
    <p class="value"><variable name="value" /></p>
  </div>
</subroutine>

<browser mode="capture">
  <html>
    <body>
      <call name="metric-card" title="Sales" value="$125K" />
      <call name="metric-card" title="Users" value="1,247" />
    </body>
  </html>
</browser>
```

### 2. Data-Driven Tables
```xml
<subroutine name="table-row">
  <tr>
    <td><variable name="product" /></td>
    <td><variable name="revenue" /></td>
  </tr>
</subroutine>

<browser mode="capture">
  <html>
    <body>
      <table>
        <call name="table-row" product="A" revenue="$15K" />
        <call name="table-row" product="B" revenue="$23K" />
      </table>
    </body>
  </html>
</browser>
```

### 3. Python Data Visualization
```xml
<python return="true">
import json
data = [
  {"label": "Q1", "value": 25000},
  {"label": "Q2", "value": 32000},
  {"label": "Q3", "value": 28000},
  {"label": "Q4", "value": 35000}
]
json.dumps(data)
</python>

<defvar name="chartData" value="$PYTHON_RESULT" />

<browser mode="capture">
  <html>
    <body>
      <canvas id="chart"></canvas>
      <script>
        const data = <variable name="chartData" />;
        // Render chart with data
      </script>
    </body>
  </html>
</browser>
```

## Behavior Details

### In Capture Mode:

1. **Known DIRAC Tags**: Executed normally
   - `<variable>` → Expands to value
   - `<call>` → Executes subroutine
   - `<output>` → Not included in HTML
   - `<defvar>` → Defines variable
   - etc.

2. **Unknown Tags**: Output as HTML
   - `<div>` → `<div>`
   - `<h1>` → `<h1>`
   - `<table>` → `<table>`
   - Any custom tag → Literal HTML

3. **Attributes**: Preserved in output
   - `<div class="card">` → `<div class="card">`
   - Values are HTML-escaped automatically

4. **Text Content**: Included in output
   - `<p>Hello</p>` → `<p>Hello</p>`

### In Literal Mode:

- All content treated as static HTML
- No DIRAC processing
- Faster, simpler rendering

## Design Philosophy

This feature restores the original MASK design pattern where:
- Subroutines are reusable HTML generators
- Variables enable parameterization
- Composition creates complex layouts
- Separation of data and presentation
